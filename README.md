# Домашнее задание №11: Python для аналитиков ИБ

## Описание проекта
Анализ логов BOTSv1 для выявления подозрительных событий в системных журналах Windows и DNS-запросах.

## Результаты анализа

### WinEventLog
- Всего проанализировано записей: 35
- Выявлено подозрительных событий: 35
- Наиболее частые подозрительные EventID: 4624, 4688, 4703 и др.

### DNS логи
- Выявлены подозрительные домены, включая потенциально вредоносные
- Обнаружены признаки C2-коммуникаций и DGA-доменов

## Использованные библиотеки
- Pandas - для обработки данных
- Matplotlib - для визуализации
- Seaborn - для стилизации графиков

## Файлы в репозитории
- `Sadov_Mikhail_DZ11.ipynb` - основной код с анализом
- `suspicious_wineventlog.csv` - подозрительные события Windows
- `suspicious_dns.csv` - подозрительные DNS запросы
- `analysis_report.txt` - подробный отчёт
- `README.md` - описание проекта

## Выводы
В ходе анализа были обнаружены подозрительные события, требующие внимания специалистов по информационной безопасности. Наиболее критичные события требуют дополнительного расследования.
